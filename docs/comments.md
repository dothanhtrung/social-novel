# Comments

* The post composer is `.comment-form` at the bottom of each post card (`renderPostHtml` in `res/js/posts.js`). Its `data-parent-id` stays the post id. Enter submits it (`initCommentHandlers`). The form does not navigate.
* Reply does not reuse that box. The Reply button also has `data-comment-id`, so `openReplyComposer` anchors on the comment wrapper (`[data-depth]`), not the button. It adds `.reply-composer` after that comment and every deeper reply, indented to the reply depth. One reply box per card: clicking Reply on the same comment focuses it; clicking another Reply moves it. Cancel or Escape removes it. A successful reply removes it too.
* The reply form is `.comment-form.reply-form`. Its `data-parent-id` is the comment id. `data-root-id` is still the post id.
* `POST /api/post` returns `{msg, err, id}` after an insert or update (same shape as creating a room). `id` is omitted when it is 0.
* On success the page loads `GET /api/post?id=` and `GET /api/media?post=`, then inserts `renderCommentHtml` into that card. Replies go after the answered comment and its nested replies, and before that comment's reply box, using `data-comment-id` and `data-depth`. The rest of the feed is left as it is.
* The same box is used for a new post (`#add-feed-form`), Messenger (`#composer-form`), and the home friend chat (`#friend-chat-form`). Tools, picker, and the local pack live in `res/js/composer.js`. Styles live in `res/css/components.css` so Messenger, which does not load the feed stylesheet, still gets them.
* A comment box is `.comment-pill` (`renderCommentFormHtml`). The avatar sits to its left. Inside, right to left: camera (`.comment-add-media`), emoji, GIF, sticker.
* Each tool opens `.comment-picker` above the pill (below it if that would leave the screen). Escape, a click outside, or the same tool again closes it. Search filters the grid. Enter in the search box does not send the comment.
* Emoji is inserted at the caret in `textarea[name=content]`. A photo or video is kept on `.comment-media-input` and previewed until Enter. A sticker or GIF is fetched from `/assets/stickers` or `/assets/gifs`, put on that input, and the form is submitted with no text. Comment pictures use `.comment-attach-img` so they stay small.
* The pack is generated by `python3 res/assets/make_comment_pack.py` (Pillow and ImageMagick). No key and no outside host.
